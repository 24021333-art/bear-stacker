## Bear Stacker - 2D Stacking Game

* A simple 2D stacking game where players balance bears of different shapes and sizes to achieve the highest possible score.
* This project was developed as a team project to practice C++ programming and basic game development concepts.

## Features

* Core Gameplay: Stack falling objects carefully to maintain balance and avoid collapse
* Physics Logic: Basic collision detection and gravity simulation
* Game Logic: Score system based on stacking performance and stability
* UI/UX: Simple interface with score display and visual feedback

## Tech Stack

Language: C++ (C++17)
Build System: CMake
Tools: Visual Studio Code, Git

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/aitran-pham/bear-stacker.git
   ```
2. Generate build files:

   ```bash
   mkdir build && cd build
   cmake ..
   ```
3. Compile and run:

   * (Mac/Linux) `make && ./BearStacker`
   * (Windows) Open the `.sln` file in Visual Studio
